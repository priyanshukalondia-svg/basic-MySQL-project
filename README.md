# Basic-MySQL-project
A complete SQL-based Ecommerce Sales Analysis project using MySQL. This project covers database design, data modeling, joins, aggregations, customer segmentation, revenue analysis, CTEs, subqueries, and window functions to generate actionable business insights.

## Project Overview

This project analyzes an Ecommerce Sales Database using MySQL. The objective is to extract business insights from customer purchases, product sales, and revenue data using SQL.

The project demonstrates practical SQL skills commonly required for Data Analyst internships and entry-level analyst roles.

## Database Schema

The project consists of four tables:

### Customers

Stores customer information.

### Orders

Stores order details and links customers to purchases.

### Order Items

Stores products included in each order.

### Products

Stores product information and pricing.

## Key Business Insights

* Laptop generated the highest revenue among all products.
* A small number of customers contributed a significant portion of total revenue.
* VIP customers generated the majority of sales.
* Revenue distribution was highly concentrated among top-performing products.
